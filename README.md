# 과제 09: 모든 정점 쌍의 최단경로 탐색

## 1. 과제 개요

이 프로그램은 C 언어를 사용하여 가중치 무방향 그래프를 생성하고, 모든 정점 쌍 사이의 최단경로를 구하는 프로그램입니다.

정점 10개와 간선 20개를 무작위로 생성하고, Floyd-Warshall 알고리즘을 사용하여 총 45개 정점 쌍의 최단경로와 최단거리를 계산합니다.

## 2. 프로그램 구현 내용

### 2.1 그래프 생성

- 정점은 0부터 9까지 총 10개입니다.
- 간선은 총 20개를 생성합니다.
- 각 간선의 가중치는 1부터 100 사이의 난수로 설정합니다.
- 자기 자신을 연결하는 간선과 중복 간선은 생성하지 않습니다.
- 처음에 9개의 간선으로 모든 정점을 연결하고, 나머지 11개의 간선을 추가하여 연결 그래프를 생성합니다.

### 2.2 최단경로 탐색

모든 정점 사이의 최단경로를 구하기 위해 Floyd-Warshall 알고리즘을 사용했습니다.

`dist` 배열에는 최단거리를 저장하고, `next` 배열에는 최단경로를 복원하기 위한 정보를 저장합니다.

중간 정점을 거쳐 가는 경로의 가중치 합이 기존 경로보다 작으면 최단거리를 갱신합니다.

### 2.3 결과 출력

프로그램은 다음 내용을 출력합니다.

1. 그래프의 정점 수와 간선 수
2. 생성된 20개 간선과 가중치
3. 모든 45개 정점 쌍의 최단경로
4. 각 정점 쌍의 최단거리
5. 전체 정점 쌍의 수

## 3. 결과 확인

프로그램 실행 결과 다음 사항을 확인했습니다.

- 정점 10개, 간선 20개 생성
- 모든 간선의 가중치가 1~100 범위에 포함
- 자기 자신을 연결하는 간선과 중복 간선 없음
- 모든 정점이 연결된 그래프 생성
- 45개 정점 쌍의 최단경로와 최단거리 출력

예를 들어 0번 정점에서 9번 정점까지의 최단경로는 다음과 같습니다.

`0 → 8 → 3 → 6 → 5 → 9`

최단거리:

7 + 7 + 8 + 36 + 19 = **77**

직접 연결된 간선의 가중치는 90이지만, 다른 정점을 거쳐 가면 77이므로 더 짧은 경로를 찾을 수 있습니다.
